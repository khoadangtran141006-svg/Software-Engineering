# \# BrewLite

# 

# BrewLite is a cashless coffee ordering application developed for the Software Engineering course.

# 

# The application allows customers to select drinks, customize products, add items to a cart, place orders, make cashless payments, and receive order confirmation for pickup.

# 

# \## 1. Project Vision

# 

# BrewLite aims to provide a fast and convenient cashless drink ordering experience.

# 

# The main goal is to reduce waiting time at the coffee store and allow customers to pick up their drinks after placing an order.
